# مراجعة البنود — العقود التجارية المصرية

راجع هذا الملف من أوله إلى آخره. لكل بند: ما هو، وماذا يفعل القانون المصري به، والخطر،
والحل، والبديل. وأرقام المواد مُتحقَّق منها مقابل المرجع التشريعي التالي؛ فإذا اعتمد
بند على أمر غير مذكور فيه، فاذكر ذلك في القسم الخامس من المُخرَج بدل التخمين.

المرجع التشريعي المُتحقَّق منه:

## ١. الأطراف والأهلية

**راجع**
- مطابقة الأسماء القانونية لقيود السجل التجاري حرفاً بحرف. خُذ المستخرج لا الاسم
  التجاري.
- صلاحية المُوقِّع. من وقّع وهو ليس عضواً في مجلس الإدارة، أو كانت صلاحيته قد
  انتهت، يخلق نزاعاً يمكن تجنبه.
- هل هناك طرف محجور عليه؟ **المادة ١١٤ من القانون المدني (Civil Code Art. 114)**
  — الأعمال الواقعة **بعد تسجيل** أمر الحجر **باطلة**؛ وأما ما قبلها فلا يبطل إلا
  إذا كانت الحالة مشهورة أو كان الطرف الآخر يعلم بها.
- القُصّر. **المواد ١١٠–١١٢ (Civil Code Arts. 110–112)** — من لم يبلغ الثامنة
  عشرة؛ فالأفعال تكون باطلة أو قابلة للإبطال أو صحيحة بحسب كونها نافعة محضة أو
  ضارة محضة أو مختلطة.
- هل الشركة المقابلة قائمة فعلاً؟ الاسم التجاري ليس شركة.

**الخطر:** التوقيع مع طرف غير موجود أو موصوف وصفاً غير صحيح: أرخص العيوب إصلاحاً،
وأغناها كلفةً إن اكتُشف لاحقاً.

## ٢. موضوع العقد ونطاقه

**راجع**
- هل الالتزام **محسوم بما يكفي**؟ **المواد ١٣١–١٣٧ من القانون المدني (Civil Code
  Arts. 131–137)** في موضوع العقد وسببه.
- **المادة ٩٥ (Civil Code Art. 95) — مهملة على نطاق واسع.** إذا اتفق الطرفان على
  جميع **المسائل الجوهرية** وأحالا المسائل التفصيلية وحدها إلى ما بعد ذلك،
  **ولم يشترطا انقضاض العقد لعدم الاتفاق، فيُعدّ العقد منعقداً**، وتُحسم النقاط
  المُحالة إلى المحكمة بحسب طبيعة التصرف والقانون والعرف والعدالة.
  ➜ وهذا يخدم الطرفين معاً. إن كنت مورّداً والنطاق يبدو مفتوحاً، فقد تكون ملتزماً
  بعملٍ لا يحدّده إلا ما كان محالاً. فاذكر ذلك.
- **المادة ١٤٨(٢) (Civil Code Art. 148(2))** — العقد لا يقتصر على ما ورد فيه، بل
  يشمل ما هو من **مستلزماته** وفق القانون والعرف والعدالة. وهي أنفع مادة في القانون
  المدني لصائغ العقود، وهي تخدم الطرفين معاً.
- مستويات الخدمة، ومعايير القبول، والمخرجات. وإذا لم توجد آلية قبول فلا يوجد معيار
  قابل للنفاذ.

**الحل:** أرفق مواصفة فنية، وحدّد من يقوم بالقبول وخلال أي مدة.

## ٣. السعر والعملة والدفع

**راجع**
- **العملة.** الجنيه المصري أم عملة أجنبية؟ إن كانت أجنبية: أي سعر، وفي أي
  تاريخ، ومن يتحمّل تحرّك سعر الصرف، وهل ثم إشكال مصري متعلق بالتحويل من مصر أو
  إليها. لا تترك هذا ضمنياً.
- **المادة ٢٢٦ (Civil Code Art. 226) — الفائدة الافتراضية:** **٤٪ سنوياً في المسائل
  المدنية، و٥٪ سنوياً في المسائل التجارية**، وتجرى من تاريخ المطالبة القضائية ما لم
  يحدّد العقد أو العرف التجاري تاريخاً آخر.
- **المادة ٢٢٧(١) (Civil Code Art. 227(1)) — السقف الذي لا تتجاوزه الصياغة.**
  مهما اتفق الطرفان على نسبة، **فما زاد على السعر القانوني يُخفَّض إلى ٧٪** مع ردّ
  الزيادة. والبند الذي يَعِد بنسبة ١٥٪ لا يبطل، بل **يُقصّ بهدوء إلى ٧٪**. والصائغون
  يَعِدون بأكثر مما يستحقون هنا باستمرار ودون علم.
- **المادة ٢٣٢ (Civil Code Art. 232)** — لا فوائد على الفائدة المركَّبة؛ ولا تتجاوز
  إجمالي الفوائد رأس المال، إلا إذا اقتضى العرف التجاري خلاف ذلك.
- **المادة ٣٤٣ (Civil Code Art. 343)** — إذا استحقت المصروفات والفوائد ورأس المال
  معاً، فإن الدفعات تُوجَّه **أولاً إلى المصروفات، ثم الفوائد، ثم رأس المال**.
  اعرف ذلك قبل أن تتفاوض على بند يقول «الدفعة الأولى تُسدِّد كل شيء».
- **المواد ٣٤٤–٣٤٥ (Civil Code Arts. 344–345)** — عند وجود عدة ديون من ذات النوع
  يجوز للمدين أن يحدّد أيها سدَّد؛ فإن لم يحدّد، سُدِّد الدين الأقلّ عبئاً على المدين،
  وإذا تساوى العناء كان الاختيار للدائن.
- **المادة ٢٧٢ (Civil Code Art. 272)** — الالتزام المستحق الأداء «عند القدرة»
  يحدّد له القاضي تاريخاً معقولاً بحسب وسائل المدين وما تقتضيه عناية الشخص
  الحريص. لا تصُغ التزام أداء غير محدود الأجل يربط نفسه بـ«عند القدرة».

**الحل:** حدّد العملة، وآلية التسعير، وتاريخ الاستحقاق، ونسبة فائدة تصمد أمام
**المادة ٢٢٧ (Civil Code Art. 227)**.

## ٤. الشرط الجزائي والتعويض المتفق عليه

هنا تعِد الصياغة المصرية بأكثر مما تستحق في أغلب الأحيان.

**راجع**
- **المادة ٢٢٤ (Civil Code Art. 224) — لا يستحق التعويض المتفق عليه إذا أثبت المدين
  أن الدائن لم يلحقه ضرر**، وللمحكمة تخفيضه إذا كان مبالغاً فيه بوضوح أو نُفِّذ
  جزئياً. والاتفاقات المخالفة **باطلة**.
  ➜ فالشرط الجزائي **ليس دفعة تلقائية**. بل هو نقطة بداية إثبات يطعن عليها الطرف
  الآخر بإثبات عدم وقوع ضرر.
- **المادة ٢٢٥ (Civil Code Art. 225) — السقف.** لا يجوز مطالبة الخسارة التي تتجاوز
  المبلغ المتفق عليه **إلا إذا وقع من المدين احتيال أو خطأ جسيم**.
  ➜ فالشرط الجزائي **سقف للمطالبات العادية لا حدّ أدنى لها**. فإذا أراد العميل
  المطالبة بأكثر من الغرامة عن إخلال سيّئ، فعليه إثبات الاحتيال أو الخطأ الجسيم.
- هل المبالغ متمايزة عن التزامات الأداء الفعلية؟ الغرامة التي تعيد صياغة الالتزام
  الأصلي لا تضيف شيئاً.

**ملاحظة صياغية:** متى كانت الغرامة معبَّراً عنها بحسب الخسارة المتوقَّعة فعلاً،
فاذكر ذلك في الديباجة. فهي لا تُقيِّد المحكمة، لكنها تدعم حجّة **المادة ٢٢٤ (Civil
Code Art. 224)** بأن الرقم مسنود بدليل لا مجرَّد تعسّف.

**الحل:** أبقِ الرقم قابلاً للدفاع عنه؛ وفكّر في تدبير تعويضي منفصل، منصوص على أنه
**غير حصري**، للاحتيال والخطأ الجسيم، حتى لا يضيع استثناء **المادة ٢٢٥ (Civil Code
Art. 225)** بحجة التأويل الضيّق.

## ٥. التسليم والقبول والملكية والمخاطر

**راجع**
- **المادة ٣٤٧ (Civil Code Art. 347)** — التسليم في الشيء المعين في المكان الذي كان
  فيه حين نشأ الالتزام؛ وإلا في مسكن المدين وقت التنفيذ، أو في محل عمله إذا كان
  الالتزام متعلقاً به.
- شروط إنكوترمس (شروط التجارة الدولية)؟ إن استُخدمت، فحدّد **النسخة واللفظ الحرفي**
  (نسخة ٢٠٢٠ لا نسخة ٢٠١٠). والإحالات المبهمة مصدر متكرر للنزاعات.
- **المادة ٢٤٦ (Civil Code Art. 246) — حق الحبس.** من التزم بالتسليم **يجوز له
  احتجاز الشيء** حتى يقدّم الدائن المقابلَ أو يقدّم ضماناً كافياً. فإن كان عميلك
  يحتجز بضائع مقابل مبالغ لم تُسدَّد، فهذه هي المادة — وهي تعني أيضاً أن العميل لا
  يستطيع أن يطالب بالتسليم مجتمعةً مع الامتناع عن الدفع.
- متى ينتقل الخطر؟ عند التسليم، أم عند القبول، أم عند التوقيع؟ حدّده.
- **المادة ١٤٦ (Civil Code Art. 146)** — الالتزامات والحقوق الشخصية المتصلة بالشيء
  تنتقل إلى **الخلف الخاص** لحظة انتقال الشيء، إذا كانت من مستلزماته **والمشتري
  كان يعلم بها وقت الانتقال**. شرط العلم مهم في الملكية، وفي بنود الملكية الفكرية
  والترخيص.

**الخطر:** إهمال انتقال المخاطر في عقد بضائع هو الموضع الذي تختفي فيه الهوامش في
صمت.

## ٦. القوة القاهرة

**راجع**
- ⚠️ **لا يوجد في مصر نظام تشريعي عام للقوة القاهرة.** ويعمل البند بعباراته وحدها.
  واذكر ذلك في المراجعة بدل افتراض قاعدة خلفية.
- هل يذكر الأحداث، أم يتركها لمعيار عام؟ المعيار العام موضع التقاضي.
- **مهلة الإخطار** — إلى مَن، وبأي وسيلة، وخلال أي وقت بعد العلم بالحدث.
- **واجب الحدّ من الضرر** — هل يُلزم الملزم بالحدّ من الضرر، وماذا يحدث إن لم
  يفعل.
- **حق الإنهاء طويل الأجل** — وبدونه قد يعلّق حدثُ القوة القاهرة العقد إلى أجل غير
  معلوم ويحتجز الطرفين.
- **الدفع المسبق** — ما مصير المبالغ المدفوعة سلفاً. والإجابة الافتراضية عادةً أن
  لا شيء يحدث حتى ينتهي العقد، وقد يُترك مبلغ كبير سلفاً معلّقاً.
- التزامات الدفع تُستثنى عادةً من القوة القاهرة. فاذكر ما إذا كانت كذلك أم لا.

**الخطر:** **مرتفع** حيث يمتد العقد في ذيل طويل من مخاطر التسليم ولا ينص على إنهاء
طويل الأجل. هذه أكثر ملاحظة تكراراً في العقود التجارية المصرية التي تُراجَع من
خارج مصر.

## ٧. الشروط والأجل

**راجع**
- **المواد ٢٦٥–٢٧٠ (Civil Code Arts. 265–270)** في الشرط المعلق والشرط الفاسخ.
  - **المادة ٢٦٦ (Civil Code Art. 266)** — الالتزام المشروط بشرط مستحيل، أو بشرط
    يخالف الآداب والنظام العام، **لا وجود له**.
  - **المادة ٢٦٧ (Civil Code Art. 267)** — الشرط المعلق الموقوف تحققه **منفرداً على
    إرادة الواعد** يعدّ غير موجود. صُغ شرطاً حقيقياً.
  - **المادة ٢٧٠ (Civil Code Art. 270)** — للشرط **أثر رجعي** إلى وقت نشوء
    الالتزام، ما لم تدلّ إرادة الطرفين أو طبيعة العقد على خلاف ذلك.
- **المادة ٢٧٣ (Civil Code Art. 273)** — يسقط أجل **المدين** بالإفلاس أو بإعلان
  الإعسار، وحين يضعف هو بنفسه الضمان الخاص؛ ولكن إذا لم يكن الضعف منسوباً إليه لم
  يسقط الأجل إلا إذا طالب الدائن باستكمال الضمان.
- **المادة ٢٧٤ (Civil Code Art. 274)** — مع الأجل المعلق يجوز للدائن أن يطالب
  **بضمان لأسباب معقولة** إذا خاف على دَينه الإفلاس.
- إخطار الإنهاء: الوسيلة والعنوان ومهلة التصحيح، وما يحدث للأعمال الجارية ولمبالغ
  المدفوعة.

## ٨. المسؤولية والتعويض والتأمين

**راجع**
- سقف المسؤولية، وما **المستثنى** منه. السقف بلا استثناءات عقد مختلف تماماً عن
  السقف ذي استثناء الاحتيال أو الإهمال الجسيم أو السرية.
- التعويض: هل هو متوافق مع **المادة ٢٢٥ (Civil Code Art. 225)**؟ الصائغون يكتبون
  تعويضاً يبدو شرطاً جزائياً تعاقدياً، ويجب فهمه في ضوء **المادة ٢٢٤ (Civil Code
  Art. 224)** و**المادة ٢٢٥ (Civil Code Art. 225)**.
- المسؤوليات المستثناة — الوفاة أو الإصابة الشخصية، والاحتيال، وحقوق الملكية
  الفكرية — اذكرها صراحةً بدل تركها للتأويل.

## ٩. السرية

**راجع**
- هل هذا عقد **تجاري** أم مدني؟ فهو يغيّر نسبة الفائدة الافتراضية (**المادة ٢٢٦ من
  القانون المدني / Civil Code Art. 226**) ولا يغيّر غير ذلك تقريباً — فالقانون المدني
  هو الحاكم في الحالتين.
- المدة، وهل تبقى الالتزامات قائمة بعد الإنهاء (ويجب أن تبقى — فاذكر ذلك).
- الإفصاحات المسموح بها: الإلزام القانوني أو الرقابي، والمستشارون المهنيون، وشركات
  المجموعة. عرّف كلاً منها.
- الإرجاع أو الإتلاف عند الإنهاء، مع استثناء الاحتفاظ القانوني و**النسخ الاحتياطية
  الآلية** (التي لا يمكن عملياً محوها).
- جزاء الإخلال — ولاحظ أن شرط الغرامة على إخلال السرية يخضع للمواد ٢٢٤–٢٢٥ من
  القانون المدني كأي شرط آخر.

**الخطر:** بنود السرية الخالية من استثناء الإفصاح المسموح تُخترق عملياً من اليوم
الأول استجابةً لطلبات قانونية عادية.

## ١٠. الملكية الفكرية

**راجع**
- **قانون حماية حقوق الملكية الفكرية رقم ٨٢ لسنة ٢٠٠٢** — حقوق المؤلف في **الكتاب
  الثالث**. **المواد ١٦٠–١٦٥ (Art. 160–165)** في المدة: حياة المؤلف **زائد خمسين
  سنة**؛ والمؤلفون المشتركون إلى وفاة آخر مؤلف باقٍ؛ والأعمال الجماعية خمسون سنة من
  النشر متى كان صاحب الحق شخصاً اعتبارياً، وإلا كانت حياة المؤلف زائد خمسين؛
  **والفنون التطبيقية خمس وعشرون سنة (المادة ١٦٤ / Art. 164)**؛ **والمؤدّون خمسون
  سنة (المادة ١٦٦ / Art. 166)**.
- **المادة ١٤٣ (Art. 143)** — **الحقوق الأدبية دائمة لا تسقط بالتقادم ولا تنتقل**.
  و**المادة ١٤٥ (Art. 145)** تجعل أي تصرف فيها **باطلاً بطلاً مطلقاً**.
  ➜ فبند ينقل «جميع الحقوق، ومنها الحقوق الأدبية» باطل في عنصر الحقوق الأدبية. انقل
  الحقوق المالية، وتعامل مع الحقوق الأدبية بالتنازل عن ممارستها أو بالتعهد بعدم
  ممارستها، لا بالإسناد.
- **المادة ١٤٤ (Art. 144)** — أمر منع التداول يتطلب **تعويضاً عادلاً مقدماً**
  لصاحب الحقوق المالية، **وإلا كان الأمر باطلاً**. شرط مفاجئ؛ فلا تعِد بهذا التدبير
  تعهداً عابراً.
- سياق العمل أو الخدمة: لمن يملك المخرجات التي ينتجها المتعاقد.
- التسجيل في مصر (براءات الاختراع والعلامات) أم البناء على حقوق غير مسجَّلة؟ وبيانات
  تسجيل العلامات والبراءات في المرجع.
- مواد الغير والمصادر المفتوحة داخل المخرجات.

## ١١. القانون الحاكم

**راجع**
- سمِّ القانون، لا «قوانينه». عبارة «قوانين جمهورية مصر العربية» عملية، لكنها تترك مسألة
  **المصادر غير التشريعية** مفتوحة — والعرف التجاري له وزن في مصر ويختلف باختلاف
  القطاع.
- إذا كانت الصفقة مدنية وتجارية في آن، فاذكر **المادة ٣ من قانون التجارة** — فهي
  تنطبق على **التزامات التاجر فقط**، لا على العقد كله.
  (Commercial Code Art. 3)
- **المادة ١ من القانون المدني (Civil Code Art. 1)** — حيث لا يوجد نص، يحكم القاضي
  بالعرف، ثم بمبادئ الشريعة الإسلامية، ثم بالطبيعة والعدالة. وهذا السلّم جزء من
  القانون المصري، ومن المفيد نقله إلى عميل أجنبي، لأن عبارة «لا توجد قاعدة» لا
  تعني «العقد هو الحاكم».

## ١٢. الصياغات النمطية التي لا تعمل في مصر

أشر إليها أو أعد صياغتها:

| الصياغة النمطية | المشكلة |
|---|---|
| «استبعاد الأضرار غير المباشرة» | تُقرأ في ضوء **المادة ٢٢٥ (Civil Code Art. 225)** — لا يستحق التعويض المتفق عليه بغير ضرر، ولا تُطالب الخسارة الزائدة إلا بالاحتيال أو الخطأ الجسيم. والبند لا يؤدي الوظيفة التي يفترضها صائغ قاد من نظام قانون آخر. |
| «لا يوجد تعديل للظرف الطارئ، والعقد مُلزِم» | **المادة ١٤٧(٢) (Civil Code Art. 147(2))** تُجيز للمحكمة تخفيض التزام جعلته ظروف استثنائية غير متوقعة مرهقاً، وتُبطل أي اتفاق يخالف ذلك. هذا البند لا يستبعد المراجعة القضائية، كما أنه يكشف للطرف الآخر أن العميل يرجّح وجود ظرف طارئ. |
| «قابلية التجزئة» | ليست قاتلة بذاتها، لكن لاحظ **المادة ١٤١ (Civil Code Art. 141)** — العقد الباطل يُمكَن التمسُّك به **من تلقاء المحكمة** ولا يصححه التصحيح. والبطلان الجزئي تُعالَج في **المواد ١٤٣–١٤٤ (Civil Code Arts. 143–144)**، حيث يُعامَل العقد الباطل أو القابل للإبطال المتضمّن أركان عقد آخر صحيح على أنه ذلك العقد. وبند قابلية التجزئة لا ينقذ بنداً مخالفاً للقانون. |
| «الاتفاق الكامل» | تضعفه **المادة ١٤٨(٢) (Civil Code Art. 148(2))** — فالعقد يشمل مستلزماته وفق القانون والعرف والعدالة، لا نصّه وحده. |
| «الإخطار بالبريد الإلكتروني» | ضعيف. **المادة ٩١ (Civil Code Art. 91)** — التعبير يسري متى وصل إلى علم المخاطَب، مع **افتراض التبليد، وهو افتراض قابل للإببات**. والإخطارات ذات الآثار تحتاج إلى آلية توصيل تستطيع إثباتها. |
| «تحديد سقف التعويضات» | قارِنه بالمادة ٢٢٤ من القانون المدني (Civil Code Art. 224) قبل معاملة التعويض على أنه مستحق عند الإخلال. |

## تقدير الخطر

| التصنيف | المعنى |
|---|---|
| **حرج** | باطل، أو غير قابل للنفاذ، أو يعرّض العميل لأمر لا يستطيع تسعيره. انسحب أو أعد الهيكلة. |
| **مرتفع** | يكلّف مالاً حقيقياً أو حقاً حقيقياً، والصياغة الحالية تُفقده. صحّحه قبل التوقيع. |
| **متوسط** | ملتبس، أو يترك نزاعاً شائعاً دون حسم. صحّحه إن تحرّك الطرف الآخر؛ وإلا فسجّله. |
| **منخفض** | تفاصيل إدارية، أو خطر قبله العميل عن علم. |

لا تُضخِم. المراجعة التي كل بنودها مرتفعة هي مراجعة بلا أولويات، وسيتجاهل العميل كل
ما فيها.
