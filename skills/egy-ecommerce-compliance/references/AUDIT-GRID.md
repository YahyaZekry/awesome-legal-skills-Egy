# Audit grid — Egyptian e-commerce

Work top to bottom. Status per item: **Compliant** · **Not compliant** ·
**To correct** · **To verify**.

Priority is stated per item. Do not re-rate priorities to make the report feel
balanced — a missing Arabic page is not the same as a missing warranty sentence.

---

## 2. Pre-contract disclosure (Art. 37) — HIGH

All eleven must be present, **clearly and explicitly**, before the consumer can
commit.

| # | Item | Present? |
|---|---|---|
| 2.1 | Supplier name, address, telephone, email | |
| 2.2 | **Commercial-register number** | |
| 2.3 | **Tax card** | |
| 2.4 | Whether the supplier is legally organised; professional capacity; registering professional body | |
| 2.5 | Manufacturer or importer identification | |
| 2.6 | Product source, specifications, essential characteristics | |
| 2.7 | **How to use it** | |
| 2.8 | **Risks arising from use** | |
| 2.9 | Price and all additions — **fees, taxes, shipping** | |
| 2.10 | **Duration of the offer** | |
| 2.11 | **The warranty offered** | |
| 2.12 | **After-contract services** | |
| 2.13 | Duration for recurring services | |
| 2.14 | **Delivery date and place**, and charges on delivery | |
| 2.15 | **Withdrawal terms, including the period** | |
| 2.16 | Maintenance-centre data and arrangement, where applicable | |
| 2.17 | **The contracting data that will be sent on completion** | |

⚠️ Items 2.7, 2.8, 2.15 and 2.17 are the ones usually missing. "How to use it"
and "risks" are for **services and consumables** especially, and are exactly what
Art. 9 deceptive-conduct analysis turns on.

## 4. Returns and withdrawal (Arts. 17, 21, 40, 41) — HIGH

| # | Check | Status |
|---|---|---|
| 4.1 | **14-day** withdrawal from receipt of goods, stated to the consumer | |
| 4.2 | Refund **by the same payment method** within **7 days** of return | |
| 4.3 | The policy states **who bears shipping and return costs** (default: consumer, unless contract provides otherwise) | |
| 4.4 | **Late-delivery handling** — if you delay, the consumer's window is 14 days from delay or 30 days from receipt, whichever is longer, refund is **immediate**, and **you bear all shipping** | |
| 4.5 | Art. 41 exceptions are only those six — check you have not written extra ones | |
| 4.6 | Digital goods: the **seal** condition is disclosed **before** purchase | |
| 4.7 | In-person 14-day no-reason return disclosed where you have physical presence | |
| 4.8 | Defective goods: **30 days** from receipt, exchange or refund at no cost | |
| 4.9 | Time-sharing: **14 days** from signing, no reasons, no expenses | |

⚠️ **4.4 is the expensive one.** Test it as a scenario, not a sentence — ask "what
happens if we are nine days late?" and check the process actually does what the
policy says.

## 5. Void clauses (Art. 28) — HIGH, but the fix is deletion

Search your terms, checkout, invoices and order emails for:

- waiver of statutory consumer rights
- "no refunds under any circumstances"
- "not liable for delivery delays" / "not liable for non-conformity"
- limitation of liability below what the Law requires
- forum clauses that oust the CPA or the Economic Courts

**All of these are void.** Remove them. Do not soften them — soften-then-keep is
still void, and it signals that nobody read the Law.

## 6. Pricing and invoicing (Arts. 7, 10, 11) — MEDIUM/HIGH

| # | Check | Status |
|---|---|---|
| 6.1 | Prices displayed clearly | |
| 6.2 | Prices **inclusive of taxes and other financial charges** (VAT) | |
| 6.3 | No "excl. VAT" or "from EGP X" presentation | |
| 6.4 | Invoice issued on every sale | |
| 6.5 | Invoice shows **tax registration number** | |
| 6.6 | Invoice shows date, price, specifications, nature, type, quantity | |
| 6.7 | Invoice in Arabic (Art. 5) | |

⚠️ **Art. 11** — a defective invoice does not invalidate the sale. It lets the
**consumer prove everything by any means**. So a missing invoice hands the customer
the argument. Fix the invoice, and treat the tax registration number as a
go-live blocker.

## 8. Warranty and after-sales (Arts. 22, 23, 24, 26) — MEDIUM

| # | Check | Status |
|---|---|---|
| 8.1 | Durable goods carry a stated warranty of **at least 2 years** | |
| 8.2 | If installation is involved, the warranty runs from **actual installation**, capped at **2 months**, and you issue a receipt stating the operation date | |
| 8.3 | Warranty covers inspection, repair, **original spare parts**, technician travel, transport both ways, installation and operating costs | |
| 8.4 | Periodic-maintenance intervals communicated | |
| 8.5 | If you fail to repair: **replace new, or refund** — stated | |
| 8.6 | **Repeated-defect rule** understood: same defect **more than twice in the first year** → replace new or refund | |
| 8.7 | Service/finishing work warranted **1 year**, **3 years** if fraud or gross negligence | |
| 8.8 | Receipt issued at contracting and before work starts | |
| 8.9 | Maintenance centres and original/approved spare parts available; changes notified to the CPA | |
| 8.10 | **Defect reporting to the CPA within 7 days** is a known process, and the health/safety escalation (immediate notification, suspend, warn consumers) has an owner | |

⚠️ 8.10 is an **institutional** gap, not a page gap. Most sellers have no process
for it at all. Ask who owns it.

## 9. Consumer data — HIGH

| # | Check | Status |
|---|---|---|
| 9.1 | Express consent obtained before any marketing (Art. 29) | |
| 9.2 | Consent is separate from the terms of sale | |
| 9.3 | **Children's data treated as sensitive** — no collection from under-18s without handling it as sensitive data | |
| 9.4 | Every tool that receives customer data outside Egypt identified — host, CRM, analytics, email, payment, support, foreign parent systems | |
| 9.5 | For each, a Centre Licence/Permit path identified, **or** the transfer stopped | |
| 9.6 | No SCC/BCR reliance — **no adequacy list and no SCC route exists in the enacted text** | |
| 9.7 | CCTV: public-place footage **not** transferred outside Egypt | |
| 9.8 | Data subject rights process exists; **fee cap EGP 20,000** understood | |
| 9.9 | Law 151/2020 compliance deadline **1 November 2026** on the roadmap | |

⚠️ 9.4 is the one to run first. Most Egyptian shops do not know that their web
host is outside Egypt, and that is a cross-border transfer under **Art. 14** of
Law 151/2020 requiring a Centre Licence or Permit.

## Rating

| Rating | Meaning |
|---|---|
| **Critical** | Void contract term, missing Arabic, or a returns/delay obligation that transfers your cost to you. Fix before taking another order. |
| **High** | Art. 37 disclosure missing, no Art. 38 correction window, defective invoice, data transfer with no basis, missing defect-reporting process |
| **Medium** | Warranty wording, pricing presentation, advertising claims |
| **Low** | Housekeeping |

A report where everything is Critical is a report with no priorities, and it will
be ignored. Section 1 failing is Critical; a missing warranty sentence is Medium.
