# شبكة التدقيق — التجارة الإلكترونية في مصر

اعمل على هذا الملف من أوله إلى آخره. الحالة لكل بند: **مطابق** · **غير مطابق** ·
**يحتاج تصحيح** · **يحتاج تحقق**.

الأولوية مذكورة مع كل بند. لا تُعَدّ تقييم الأولويات ليبدو التقرير متوازناً — فغياب
صفحة بالعربية ليس كغياب جملة الضمان.

## ٤. الإرجاع والانسحاب (المواد ١٧، ٢١، ٤٠، ٤١ — Art 17, 21, 40, 41) — مرتفع

| # | الفحص | الحالة |
|---|---|---|
| 4.1 | الانسحاب خلال **١٤ يوماً** من استلام السلع، مبيّناً للمستهلك | |
| 4.2 | الاسترداد **بنفس وسيلة الدفع** خلال **٧ أيام** من الإرجاع | |
| 4.3 | السياسة تبيّن **من يتحمّل مصاريف الشحن والإرجاع** (الافتراضي: المستهلك، إلا إذا نصّ العقد على خلاف ذلك) | |
| 4.4 | **معالجة تأخير التسليم** — إن تأخّرت، تكون نافذة المستهلك ١٤ يوماً من التأخير أو ٣٠ يوماً من الاستلام، أيهما أطول، والاسترداد **فوري**، و**أنت تتحمّل كل مصاريف الشحن** | |
| 4.5 | استثناءات المادة ٤١ هي هذه الستّة فقط — تحقّق أنك لم تكتب استثناءات إضافية | |
| 4.6 | المنتجات الرقمية: شرط **الختم** مُفصَّح عنه **قبل** الشراء | |
| 4.7 | حق الإرجاع الحضوري خلال ١٤ يوماً دون إبداء أسباب مُفصَّح عنه إن كان لديك مقرّ فعلي | |
| 4.8 | السلع المعيبة: **٣٠ يوماً** من الاستلام، استبدال أو استرداد دون مصروفات | |
| 4.9 | اقتسام الوقت: **١٤ يوماً** من التوقيع، بلا أسباب وبلا مصروفات | |

⚠️ **البند 4.4 هو المكلف.** اختبره كسيناريو لا كجملة — اسأل «ماذا لو تأخّرنا تسعة
أيام؟» وتأكّد أن سير العمل يفعل ما تقوله السياسة بالفعل.

## ٥. البنود الباطلة (المادة ٢٨ — Art 28) — مرتفع، لكن الإصلاح بالحذف

ابحث في شروطك ومسار الدفع والفواتير ورسائل الطلب عن:

- تنازل عن حقوق المستهلك القانونية
- «لا استرداد تحت أي ظرف»
- «لا نتحمّل مسؤولية تأخير التسليم» / «لا نتحمّل مسؤولية عدم المطابقة»
- تحديد المسؤولية بأقل مما يتطلبه القانون
- بنود الاختصاص التي تُقصي جهاز حماية المستهلك أو المحاكم الاقتصادية

**كل هذه باطلة.** احذفها. لا تُخفّفها — فالتخفيف ثم الإبقاء يبقى باطلاً، ويوحي بأن
أحداً لم يقرأ القانون.

## ٨. الضمان وخدمة ما بعد البيع (المواد ٢٢، ٢٣، ٢٤، ٢٦ — Art 22, 23, 24, 26) — متوسط

| # | الفحص | الحالة |
|---|---|---|
| 8.1 | السلع المعمرة تحمل ضماناً معلناً **لا يقل عن سنتين** | |
| 8.2 | إذا كان هناك تركيب، فالضمان يسري من **التركيب الفعلي**، بحد أقصى **شهرين**، وتُصدر إيصالاً يثبت تاريخ التشغيل | |
| 8.3 | الضمان يشمل المعاينة والإصلاح و**قطع الغيار الأصلية** وانتقال الفني والنقل في الاتجاهين ومصاريف التركيب والتشغيل | |
| 8.4 | فترات الصيانة الدورية مُبلَّغ عنها | |
| 8.5 | إذا تعذّر الإصلاح: **استبدال جديد أو استرداد** — مذكور في السياسة | |
| 8.6 | **قاعدة تكرار العيب** مفهومة: العيب ذاته **أكثر من مرتين في السنة الأولى** ← استبدال جديد أو استرداد | |
| 8.7 | عمل التشطيب والخدمات مضمون **سنة واحدة**، و**٣ سنوات** في حالة الاحتيال أو الإهمال الجسيم | |
| 8.8 | إيصال يُصدر عند التعاقد وقبل بدء العمل | |
| 8.9 | مراكز الصيانة وقطع الغيار الأصلية أو المعتمدة متاحة، والتغييرات مُبلَّغ بها للجهاز | |
| 8.10 | **الإبلاغ عن العيب للجهاز خلال ٧ أيام** إجراء معروف، والتصعيد عند خطر الصحة أو السلامة له مسؤول محدَّد | |

⚠️ البند 8.10 فجوة **مؤسسية** لا فجوة في صفحة. أغلب البائعين لا يملكون إجراءً لها
إطلاقاً. اسأل من المسؤول عنها.

## التقييم

| التقييم | المعنى |
|---|---|
| **حرج** | شرط عقدي باطل، أو غياب العربية، أو التزام إرجاع أو تأخير ينقل التكلفة إليك. أصلحه قبل قبول أي طلب جديد. |
| **مرتفع** | غياب الإفصاح المنصوص عليه في المادة ٣٧، أو غياب مهلة التصحيح في المادة ٣٨، أو فاتورة ناقصة، أو نقل بيانات بلا سند، أو غياب إجراء الإبلاغ عن العيب |
| **متوسط** | صياغة الضمان، وطريقة عرض السعر، وادعاءات الإعلان |

التقرير الذي كل بنوده «حرج» هو تقرير بلا أولويات، وسيُهمَل. فشل القسم ١ بند حرج؛
وغياب جملة الضمان بند متوسط.
